KUNISA Next.js starter

This starter preserves your supplied KUNISA HTML, stylesheet, content, and existing browser-side interactions.
The Next.js home page displays the original site from /public/kunisa.html.

Next steps:
1. Upload this folder's contents to a GitHub repository.
2. Import that repository into Vercel.
3. Deploy and test the live site.

Note: The current journal/saved items/challenge data remain in the visitor's browser storage.
Account sign-in and cross-device sync are not implemented yet.
